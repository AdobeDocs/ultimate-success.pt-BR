# Operacionalização do Adobe Data Insights Agent no CJA

Saiba como transformar o Adobe Data Insights Agent em um fluxo de trabalho prático no Customer Journey Analytics. Esta sessão mostra como as equipes podem usar o prompt de linguagem natural para acelerar a análise, ativar insights de autoatendimento e reduzir a dependência de relatórios manuais. Se você deseja melhorar o tempo de implantação do insight e dimensionar a tomada de decisões orientadas por dados em toda a organização, esta é uma observação obrigatória.
