# Desbloquear a composição de público-alvo federado no AEP: de silos de dados a públicos-alvo unificados

Descubra como as principais organizações estão quebrando silos de dados e desbloqueando o envolvimento do cliente em tempo real com a Federated Audience Composition (FAC) no Adobe Experience Platform. Nesta sessão, os especialistas abordam como conectar facilmente o data warehouse e o Real-Time CDP para criar e ativar públicos-alvo de alto valor — sem duplicar dados. Por meio de uma demonstração ao vivo, você verá como modelar dados, criar públicos e impulsionar experiências mais personalizadas no momento usando uma interface amigável do profissional de marketing. Se você deseja dimensionar a personalização enquanto mantém a governança e a eficiência dos dados, esta sessão oferece uma visão prática e completa de como fazer isso acontecer.
