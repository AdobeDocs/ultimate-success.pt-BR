# Sites rápidos e editáveis com Universal Editor e Frameworks SSR modernos

As equipes da Web modernas queriam a liberdade das estruturas headless e modernas do JavaScript sem sacrificar a edição no contexto para os profissionais de marketing. Nesta sessão, mostramos como o Adobe Experience Manager Universal Editor e as estruturas modernas de renderização do lado do servidor (SSR) (como configurações de estilo do React e Next.js) forneceram sites rápidos e otimizados para mecanismo de pesquisa (SEO) que os autores ainda podiam editar visualmente. Explicamos como conectar o Universal Editor em aplicativos baseados em estrutura, como o SSR afetou o desempenho e o Core Web Vitals e como estruturar componentes para que os autores pudessem atualizar experiências com segurança sem romper o front-end. Se você estava planejando ou modernizando um projeto do Adobe Experience Manager (AEM) ou do Edge Delivery Services (EDS), este webinário forneceu um blueprint prático que você pode usar imediatamente.

>[!VIDEO](https://video.tv.adobe.com/v/3491408/?learn=on&enablevpops)

## Principais lições

* **Quando usar um site EDS padrão em vez de uma estrutura SSR personalizada**
Entendemos por que um site padrão do Adobe Experience Manager Edge Delivery Services (EDS) era o melhor padrão para a maioria dos projetos e quando fazia sentido criar camadas no Universal Editor em um aplicativo existente (como uma loja ou portal) em vez de reconstruir.

* **Como o Universal Editor se conectou ao EDS e às estruturas existentes**
Vimos como o Universal Editor se encaixa em uma configuração típica do AEM EDS e como os mesmos conceitos se aplicavam ao conectá-lo a um aplicativo SSR do estilo React ou Next.js já em produção.

* **SSR onde contava o equilíbrio dos padrões EDS com as necessidades de desempenho e SEO**
Aprendemos quando podíamos confiar nos padrões do EDS e quando realmente precisávamos de renderização personalizada do lado do servidor (SSR) para experiências específicas, incluindo o impacto no SEO e no Core Web Vitals para páginas de alto valor, como detalhes do produto ou páginas de aterrissagem.

* **Criação que não interrompeu os padrões do aplicativo para desenvolvedores e profissionais de marketing**
Descobrimos padrões de componentes e modelos de conteúdo que permitem aos desenvolvedores manter uma base de código limpa e mantida, além de proporcionar aos autores um poder de edição em contexto seguro, seja em um site padrão do EDS ou integrado a uma estrutura existente.
